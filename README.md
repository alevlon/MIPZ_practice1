# MIPZ Practice 1 — The Game (Renju)

Реалізація задачі **The Game** на Python для практичної роботи з
методології інженерії ПЗ (КПІ).

## Опис задачі

Гра в рендзю на дошці 19×19. Два гравці по черзі ставлять камені:
- `1` — чорний (ходить першим);
- `2` — білий;
- `0` — порожня клітинка.

Переможець — гравець, який виставив **рівно 5** своїх каменів поспіль
по горизонталі, вертикалі або діагоналі. Якщо поспіль стоїть **більше 5**
каменів одного кольору — це **не перемога**.

## Формат вводу

Перший рядок — кількість тестів `T` (1 ≤ T ≤ 11).
Далі для кожного тесту йдуть 19 рядків по 19 чисел.

## Формат виводу

Для кожного тесту:
- `0` — якщо переможця немає;
- `1` / `2` — якщо виграв чорний / білий. У цьому випадку в другому рядку
  друкуються номер горизонталі та номер вертикалі **найлівішого**
  каменя серед п'яти поспіль. Якщо п'ятірка вертикальна — обирається
  **найвищий** камінь. Координати 1-індексовані.

## Запуск

```powershell
python the_game.py < sample_input.txt
```

Очікуваний вивід:

```
1
3 2
```
