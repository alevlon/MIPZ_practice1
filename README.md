# MIPZ Practice 1 — The Game (Renju)

Реалізація задачі **The Game** на Python для практичної роботи з
методології інженерії ПЗ (КПІ).

## Опис задачі

Гра в рендзю на дошці 19×19. Два гравці по черзі ставлять камені:
- `1` — чорний (ходить першим);
- `2` — білий;
- `0` — порожня клітинка.

Переможець — гравець, який виставив **рівно 5** своїх каменів поспіль
по горизонталі, вертикалі або діагоналі. Якщо поспіль стоїть **більше 5**
каменів одного кольору — це **не перемога**.

## Формат вводу

- Перший рядок — кількість тестів `T` (1 ≤ T ≤ 11).
- Далі для кожного тесту йдуть 19 рядків по 19 чисел.
- **Порожні рядки між дошками дозволені** — їх можна використовувати
  як «абзаци» для зручного редагування `sample_input.txt`. Парсер
  їх ігнорує.

## Формат виводу

Для кожної дошки програма друкує читабельний звіт:
- «переможця немає» — якщо ніхто не виграв на цій дошці;
- ім'я переможця (чорні / білі) та координати **найлівішого** каменя
  у виграшній п'ятірці. Якщо п'ятірка вертикальна — обирається
  **найвищий** камінь. Координати 1-індексовані.

Наприкінці виводиться загальний підсумок: скільки дощок завершились
перемогою, а скільки — нічиєю.

## Запуск

PowerShell (Windows):

```powershell
Get-Content sample_input.txt | py the_game.py
```

cmd / bash:

```bash
python the_game.py < sample_input.txt
```

PyCharm: у Run Configuration увімкнути **Redirect input from** →
`sample_input.txt`.

## Структура

- `the_game.py` — розв'язок;
- `sample_input.txt` — приклад вхідних даних (10 тестових дощок,
  розділених порожніми рядками для зручності читання).
